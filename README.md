Welcome to the Infinite Parkour repo.

### Collaborating

To use this project, you can use **[Jitpack](https://jitpack.io/#efnilite/walk-in-the-park)** to get the source and include it in your preferred build method.

### Gradle

```gradle
    maven {
        url "https://jitpack.io"
    }
```

```gradle
    maven { url = uri("https://www.jitpack.io") }
```

Adding the dependency:

```gradle
    dependencies {
        implementation "com.github.HappyAreaBean:Walk-in-the-Park:Version"
    }
```

```gradle
    dependencies {
        implementation("com.github.HappyAreaBean:Walk-in-the-Park:Version")
    }
```

### Maven

```xml
<repository>
    <id>jitpack.io</id>
    <url>https://jitpack.io</url>
</repository>
 ```

```xml
<dependency>
    <groupId>com.github.HappyAreaBean</groupId>
    <artifactId>Walk-in-the-Park</artifactId>
    <version>Tag</version>
</dependency>
```
